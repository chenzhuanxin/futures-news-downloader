1数据流总览

整个工具涉及 两类数据：一类是「品种基础数据」（静态、内置）， 另一类是「品种资讯数据」（动态、实时抓取）。它们的来源完全不同。

数据类型来源获取方式是否实时
品种基础数据 公众号图文内嵌的导航页 一次解析后内置到 core/varieties.py 静态内置
品种资讯数据 东方财富 / 新浪财经 运行时按关键词实时检索并抓取正文 实时

完整数据流

关键词品种名 / 代码
→
搜索接口东财 / 新浪
→
时间过滤近 3 天
→
正文抓取段落 + 配图

全部请求都在本机发出，直接访问目标站点公开接口。 没有经过任何第三方中转服务器，也没有把数据上传到别处。

来源

3数据源一：东方财富

域名：eastmoney.com。用到一个搜索接口 + 若干文章页域名。

用途域名 / 地址
资讯检索search-api-web.eastmoney.com
文章正文finance / futures / stock / bond .eastmoney.com

3.1 搜索接口

请求方式：GET，返回 JSONP。

GET https://search-api-web.eastmoney.com/search/jsonp
      ?cb=cb
      &param={URL 编码后的 JSON}

核心参数（param 的 JSON 结构）：

{
  "uid": "",
  "keyword": "沪铜",                 // 品种关键词
  "type": ["cmsArticleWebOld"],      // 文章类型
  "client": "web",
  "clientType": "web",
  "clientVersion": "curr",
  "param": {
    "cmsArticleWebOld": {
      "searchScope": "default",
      "sort": "time",              // 按时间倒序
      "pageIndex": 1,
      "pageSize": 40,
      "preTag": "\u0001",            // 高亮标记（工具会清洗掉）
      "postTag": "\u0002"
    }
  }
}
踩坑记录：接口默认会在命中关键词处插入 <em> 高亮标签。 工具改用不可见控制符 \u0001 / \u0002 作为标记，并在解析时 清洗掉，避免控制字符混进 Word 正文。

返回结构（截取关键字段）：

{
  "result": {
    "cmsArticleWebOld": [
      {
        "title": "沪铜主力合约震荡上行…",
        "date": "2026-10-11 09:20:00",     // 发布时间
        "mediaName": "期货日报",          // 原始媒体
        "url": "https://finance.eastmoney.com/a/…",
        "code": "20261011389…",            // 文章唯一 ID
        "content": "摘要内容…"
      }
    ]
  }
}

3.2 文章页解析

抓到链接后打开文章页，解析正文与配图：

数据选择器 / 规则
标题<title>，去掉 _ 后缀
发布时间div.time
来源div.sourcebox 中的「文章来源：」
正文容器div#ContentBody
正文元素按文档顺序取 p / img / h3 / h4 / blockquote
URL 必须升级为 HTTPS：搜索结果里部分链接是 http://， 直接访问会 403。程序会自动把 http:// 换成 https://， 并带上 Referer 才能正常取到正文。

6时间窗口与筛选

时间窗口由 get_date_window(days) 生成，默认 days=3：

今天  = 运行日
昨天  = 运行日 - 1
前天  = 运行日 - 2

合法日期集合 = { 前天, 昨天, 今天 }   // 形如 "2026-10-09"
步骤规则
入库判定资讯 date[:10] 落在合法日期集合内才保留。
提前停止（东财）结果按时间倒序，一旦出现早于窗口下限的日期即停止该品种后续请求。
提前停止（新浪）本页最早时间已早于窗口下限时，停止翻页。
排序最终按发布时间倒序（最新在前）。
条数上限每个品种最多保留「每品种条数」设置值（默认 15）。
注意：筛选依据是文章的发布时间，不是抓取时间。 所以你在 11 号运行，抓到的是 9、10、11 号发布的稿件。

7跨源去重

选择「两家合并」时，同一篇稿子可能在东财和新浪都存在。去重规则：

# 标题归一化：去掉所有空白与符号，取前 26 个字符
key = re.sub(r"[\s\W_]+", "", title)[:26]

# 相同 key 只保留先出现的那条（东财优先）
  • 同源内去重：用文章唯一 ID（东财 code / 新浪 id）或 URL 判重。
  • 跨源去重：用归一化标题判重，避免「同稿多站转载」重复入档。
  • 源优先级：合并模式下东方财富先入队，因此同标题时保留东财版本。

8图片抓取与过滤

抓取流程

  1. 从正文块里收集图片 URL，按原文顺序保留。
  2. 下载到临时目录（带 Referer，避免防盗链）。
  3. 校验：文件体积与真实像素尺寸双重过滤。
  4. 嵌入到 Word 对应位置，随后删除临时目录。

过滤规则

规则阈值过滤对象
文件体积< 2048 字节空白图 / 占位图
真实宽度< 200 px站点图标、小按钮
真实高度< 140 px窄横幅、分割线
URL 黑名单含 logo / icon / avatar / qrcode / share_ 等页眉页脚装饰图
单篇上限最多 12 张图片过载的图集稿

Word 中的呈现

  • 按原文位置插入对应的段落之间，不集中堆到文末。
  • 居中显示，按正文宽度（16 cm）等比缩放，保证完整不裁切。
  • 图片下方统一加注「（原文配图）」，便于与正文区分。
为什么结果里没有 images 文件夹？ 图片只作中转：下载 → 嵌入 → 删除。你在 output\ 里只会看到 Word 或 ZIP，不会有一堆散图。

10内容原始媒体

东方财富与新浪财经本质上是聚合平台，它们转载各家媒体的稿件。 程序会记录每篇文章的「原始媒体」并写入 Word（来源字段）。 实测出现频次较高的有：

期货日报 东方财富研究中心 每日经济新闻 财联社 第一财经 国际金融报 界面新闻 上海证券报 · 中国证券网 21 世纪经济报道 南方财经网 中国证券报 深圳商报 · 读创 国金证券 光大期货
