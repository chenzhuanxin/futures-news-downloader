✦这是什么

一个 Python + HTML 的本地工具：启动后在浏览器里打开一个网页界面， 勾选你关心的期货品种，一键抓取它们最近三天（今天/昨天/前天）的资讯， 导出成排版规范的 Word 文档。

📦

批量 / 单个都行

支持一键全选 88 个品种，也可只挑一两个；按名称、代码、拼音搜索，还能按夜盘/金属/农产快捷筛选。

📅

只抓近三天

严格按发布时间过滤「今天 / 昨天 / 前天」，界面顶部会实时显示当前的时间窗口。

🔀

双数据源可切换

东方财富 / 新浪财经 / 两家合并。合并时同一篇稿子会自动去重，覆盖更全。

📝

规范 Word 排版

标题黑体三号加粗居中；正文仿宋三号两端对齐、首行缩进 2 字符；原文配图按原位插入。

🖼️

图片随文呈现

配图不是堆在文末，而是落在它原本所在的段落位置，居中等比缩放、完整显示。

🗂️

两种打包方式

合并成一个 Word（每品种独立分页），或每品种一个 Word 打包成 ZIP。
